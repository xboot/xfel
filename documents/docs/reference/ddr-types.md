# DDR参数

下表列出所有支持 DDR 初始化的芯片。需要指定 `type` 的芯片列出其支持的类型名称；标注为「默认配置」的芯片无需指定 `type`，直接执行 `xfel ddr` 即可使用默认配置。未列出的芯片表示不支持 DDR 初始化。

| 芯片 | 支持的 DDR 类型 |
|------|----------------|
| D1 / D1s / F133 | `d1`、`f133` |
| H2 / H3 | `h2`、`h3` |
| H616 / H313 / H618 / T507 | `lpddr4` |
| V3s / S3 | `v3s`、`s3` |
| V851 / V853 | `v851`、`v853` |
| R528 / T113 | `r528-s3`、`t113-s3`、`t113-s4` |
| R128 | `r128-s2`、`r128-s3`、`xr875` |
| T153 | `t153-m3` |
| A40i / R40 | `ddr3`、`lpddr3` |
| A523 / A527 / T527 / MR527 | `lpddr4` |
| F1C100S / F1C200S / F1C500S | 默认配置（无需指定） |
| V821 | 默认配置（无需指定） |
| V831 | 默认配置（无需指定） |
